### Битрикс установил на VirtualBox
<img width="1060" height="272" alt="image" src="https://github.com/user-attachments/assets/f26d47ac-a4a0-4a80-9d81-1a254820c3b4" />

В процессе использования битрикса на виртуальной машине возникали следующие трудности:
1. Иногда при запуске виртуальной машины с ошибкой запускались службы mysqld и nginx, вручную запускал их с помощью systemctl,
2. Во время установки с помощью bitrix_setup с сайта битрикса архив скачивался не до конца, из-за чего пришлось его качать вручную, затем закидывать в папку, после чего продолжать процесс установки
